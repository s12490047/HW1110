Wiki 與簡報的關係

Wiki 是可驗證的知識層，簡報是它的投影結果。修改資料後重跑建置，兩邊不會分叉。

取得資料→來源卡／claim→正規化→檢查（schema）→data/*.json→build 驗證→index.html
關於 markdown 檔：GitHub Pages 不會把 .md 渲染成網頁，直接點只會看到純文字。因此每張卡的主要連結指向 GitHub 的排版版本；「原始 .md」是同源檔案，供離線或下載使用。
  • 本頁本身是靜態 HTML，無外部字型、無外部 JS／CSS，離線可開。
  • 資料異動流程：改 data/ 或 src/ → py tools/build.py → index.html 重新產生。
